## 2. Kerangka (arsitektur) Transformer

Deret `[kanal, T]` dipotong menjadi **tambalan 10 menit** (T=120 → **12 token**) lewat Conv1d stride 10 yang
memproyeksikan tiap tambalan ke **d=64**; ditambah token **[CLS]** + embedding posisi yang dipelajari; lalu
**2 lapis encoder pre‑norm** (4 kepala, FFN 128, dropout 0,1); keluaran diambil dari token [CLS] → LayerNorm → Linear(64→4).

```python
HIPER = {"epoch": 30, "lr": 1e-3, "batch": 64, "wd": 1e-2, "d": 64, "lapis": 2, "kepala": 4,
         "ffn": 128, "dropout": 0.1, "tambalan": 10, "maks_token": 256}   # tambalan 20 -> 10 (masukan per menit)

class Trf(nn.Module):
    def __init__(self):
        self.proj = nn.Conv1d(n_kanal, 64, kernel_size=10, stride=10)   # [B,6,120] -> [B,64,12]
        self.cls  = nn.Parameter(torch.zeros(1, 1, 64))
        self.pos  = nn.Parameter(torch.zeros(1, 257, 64))               # trunc_normal_(std=0.02)
        lapis = nn.TransformerEncoderLayer(64, 4, 128, 0.1, batch_first=True, norm_first=True)
        self.enc = nn.TransformerEncoder(lapis, num_layers=2)
        self.norm = nn.LayerNorm(64)
        self.kepala = nn.Linear(64, n_kelas)                            # n_kelas = 4 horizon

    def forward(self, x):                                              # x [B, 6, 120]
        x = self.proj(x).transpose(1, 2)                               # [B, 12, 64]
        x = torch.cat([self.cls.expand(len(x), -1, -1), x], 1)         # [B, 13, 64]
        x = x + self.pos[:, : x.shape[1]]
        return self.kepala(self.norm(self.enc(x)[:, 0]))              # [B, 4]  (logit)
```

**Struktur torch.nn (dari `print(model)`):** `proj: Conv1d(6,64,k=10,s=10)` · `enc: TransformerEncoder(2× [MultiheadAttention(4 kepala) + Linear 64→128→64 + LayerNorm])` · `norm: LayerNorm(64)` · `kepala: Linear(64,4)`. **Jumlah parameter: 87.748.**

## 3. Bentuk input dan output

| Tahap | Operasi | Bentuk | Keterangan |
|---|---|---|---|
| Input `X` | data | **(B, 6, 120)** | 6 kanal (suhu, log‑cahaya, daya, tegangan rel, sin/cos jam) × 120 menit |
| Proyeksi | `Conv1d(6,64,k=10,s=10)` | (B, 64, 12) | 12 token (tambalan 10 menit) |
| Token | `transpose(1,2)` | (B, 12, 64) | [B, n_token, d] |
| +CLS | `cat([CLS], token)` | (B, 13, 64) | 1 token CLS + 12 token |
| Encoder | `TransformerEncoder(2 lapis)` | (B, 13, 64) | + embedding posisi |
| Ambil [CLS] | `enc[:, 0]` | (B, 64) | representasi global |
| Kepala | `LayerNorm → Linear(64,4)` | **(B, 4)** | **logit** per horizon |
| Output `y` | dekode `KodekRegresiVektor` | **(B, 4)** | **Δsuhu °C** (+15/+30/+45/+60); suhu ramalan = suhu(t) + Δ |
