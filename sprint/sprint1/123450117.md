# Pemotong jendela dan PROTOKOL.md dari data simulasi

# Protokol Data Prakiraan Energi

## 1. Tujuan

Protokol ini mendefinisikan proses pengolahan, pemisahan,
dan evaluasi data untuk eksperimen prakiraan energi.

Selama data meja aktual belum tersedia, pengembangan
dilakukan menggunakan data simulasi.

## 2. Sumber Data

Data berasal dari simulasi yang dijalankan menggunakan:

```bash
python meja.py \
  --simulasi harian \
  --tim 28 \
  --jam 0.05 \
  --aturan ../rencana/t28-prakiraan-energi.yaml
```

Masukan yang digunakan:

- Daya per menit.
- Suhu lingkungan dari `lingkungan.csv`.
- Informasi jam dan hari.
- Riwayat pengamatan selama 120 menit terakhir.

## 3. Pembersihan Data

Satu detik pertama pada setiap kondisi dibuang.

Pembersihan dilakukan berdasarkan identitas kondisi,
bukan berdasarkan keseluruhan dataset.

Data kemudian diurutkan berdasarkan timestamp dan
diperiksa agar tidak terdapat pengamatan duplikat
atau jeda waktu yang tidak sesuai.

## 4. Pembentukan Fitur

Setiap sampel menggunakan jendela historis 120 menit.

Fitur yang digunakan:

1. Daya.
2. Suhu lingkungan.
3. Jam pengamatan.
4. Hari pengamatan.

Target adalah daya pada menit berikutnya.

Sampel yang tidak memiliki riwayat lengkap selama
120 menit tidak digunakan.

## 5. Pemisahan Dataset

Pemisahan dilakukan berdasarkan kelompok hari,
sesi, dan konfigurasi aturan.

Ketentuan:

- Data uji mencakup hari terakhir.
- Sesi dengan konfigurasi aturan berbeda ditempatkan
  pada data uji.
- Data validasi diambil dari hari terbaru yang tersisa
  setelah pemisahan data uji.
- Data latih menggunakan kelompok yang tersisa.
- Satu kelompok tidak boleh muncul pada lebih dari
  satu subset.

Pemisahan dilakukan sebelum normalisasi dan pembentukan
sampel yang berpotensi melintasi batas kelompok.

## 6. Normalisasi

Parameter normalisasi dihitung menggunakan data latih saja.

Data validasi dan data uji hanya menggunakan parameter
yang telah dipelajari dari data latih.

Tidak diperbolehkan melakukan fit normalisasi pada
data validasi maupun data uji.

## 7. Evaluasi

Metrik utama adalah Mean Absolute Error (MAE).

Hasil model dibandingkan dengan model persistensi.

Model persistensi menggunakan daya terakhir yang
tersedia sebagai prediksi untuk menit berikutnya.

Rumus:

MAE = (1/n) * sum(|y_i - y_pred_i|)

MAE persistensi:

MAE_persistensi = MAE(y_aktual, y_terakhir)

Model prakiraan dinilai berdasarkan perbandingan
MAE terhadap baseline persistensi.

## 8. Pemeriksaan Kebocoran Data

Pemeriksaan dilakukan secara programatis.

Identitas kelompok hari, sesi, dan aturan pada
data latih, validasi, dan uji harus saling terpisah.

Pemeriksaan juga mencakup rentang timestamp untuk
memastikan jendela historis tidak melintasi batas
subset.

## 9. Status Protokol

Protokol ini digunakan untuk pengembangan awal
berbasis data simulasi.

Setelah data meja aktual tersedia, kesesuaian
format data, kualitas pengukuran, dan distribusi
fitur harus diperiksa kembali.

Perubahan protokol harus didokumentasikan melalui
pull request dan diajukan kepada pembimbing.
